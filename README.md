# homwork_web_6_21_2
В задании реализованы верстка 4х пор Категории, Контакты, Главная, Каталог. 
Запуск сервера производится из web.py в SRC (http://localhost:8080)
При GET запросе к серверу возвращается страница Контакты.
При POST запросе в консоле выводятся данные из формы заполнненые пользователем, и возвращает на страницу Контакты.
## Установка:

1. Клонируйте репозиторий:
```
https://github.com/oMakom/homwork_web_6_21_2.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
poetry install
```
